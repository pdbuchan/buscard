GERBER Files for Reverse-Engineered BusCard

The following files were put into a .zip archive and sent to the board manufacturer. These are the files Elecrow requires. Your manufacturer may request something slightly different. Along with the GERBER files, I included a text file requesting gold fingers for the card edges, and a jpg image showing that I want the card edges to be chamfered.

GERBER Files
  • Bottom copper layer
  • Bottom overlay (silkscreen)
  • Bottom solder mask
  • Mill layer
  • Top copper layer
  • Top overlay (silkscreen)
  • Top solder mask
  • Drill file
