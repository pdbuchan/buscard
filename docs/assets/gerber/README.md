# GERBER files to send to PCB manufacturer

| File | Description |
|---|---|
| buscard.GBL | Bottom copper layer |
| buscard.GBO | Bottom overlay (silkscreen) |
| buscard.GBS | Bottom solder mask |
| buscard.GML | Mill layer |
| buscard.GTL | Top copper layer |
| buscard.GTO | Top overlay (silkscreen) |
| buscard.GTS | Top solder mask |
| buscard.TXT | Drill file |

At the time I had my boards manufactured, [Elecrow](https://www.elecrow.com/) told me to include a request for them to contact me regarding gold fingers.

| File | Description |
|---|---|
| PLEASE_CHAMFER_CARD_EDGES.jpg | Shows locations of PCB edges to be chamfered. |
| PLEASE_CONTACT_ME_ABOUT_GOLD_FINGERS.txt | Instruction to contact me regarding gold fingers. |
