# Website HTML files and assets

This directory is the GitHub Pages document root.

| HTML File | Description |
|---|---|
| `index.html` | The project main webpage |
| `assets/images/orig_gallery.html` | A gallery webpage for the original BusCard |
| `assets/images/new_gallery.html` | A gallery webpage for my reverse-engineered BusCard |
| `assets/gerber/gerber.html` | A webpage for the GERBER files to be sent to a PCB manufacturer |
| `assets/datasheets/datasheets.html` | A webpage listing various component datasheets |
| `assets/libraries/libraries.html` | A webpage listing my custom EAGLE libraries for various components |
| `.nojekyll` | Tells GitHub Pages to serve the files without Jekyll processing |

| File | Description |
|---|---|
| `assets/buscard.css` | Shared stylesheet for BusCard project |
| `assets/buscard_rev_a_manual.pdf` | Scan of the BusCard manual with errata incorporated |
| `assets/schematic.pdf` | The reverse-engineered BusCard schematic, rendered by EAGLE |

| Directory | Description |
|---|---|
| `assets/cam/` | The EAGLE CAM file for generating the GERBER files |
| `assets/datasheets/` | Datasheets for the various BusCard components |
| `assets/drawings/` | My original hand-drawn schematic, and other drawings I prepared |
| `assets/eagle/` | EAGLE board and schematic files |
| `assets/eprom/` | TMS-2564 EPROM binary image, as well as instructions for burning copies using the Promenade EPROM burner |
| `assets/gerber/` | The GERBER files to be sent to a PCB manufacturer |
| `assets/images/` | Photographs of the original and reverse-engineered BusCards |
| `assets/libraries/` | My custom EAGLE libraries for various components |
| `assets/parts/` | Parts lists for original and new BusCards as Microsoft Excel spreadsheets |
